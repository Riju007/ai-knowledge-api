# Project Learning Contract

This repository is both a working backend service and a structured learning project.

## How we work

1. Learn one small concept.
2. Implement it in the project.
3. Run it locally.
4. Test the behavior.
5. Inspect the result.
6. Improve it.
7. Commit the change.
8. Move to the next concept.

## Rules

- Prefer small implementations over premature abstractions.
- Do not copy-paste complete solutions for learning tasks.
- Important code should be written and understood by the learner.
- Use modern Python practices throughout the project.
- Keep infrastructure out until it is justified by the current learning stage.
- Treat Git history as part of the learning record.
